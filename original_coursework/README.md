# Original coursework review

기존 Rmd, HTML, Word 보고서, 데이터 설명, XLS/CSV는 공개용 재구성 과정에서 검토했습니다.

원 과제는 별도 원본 프로젝트에 보존되어 있습니다. 공개 저장소에는 작성자 실명 등 불필요한 개인정보, seed 미고정 당시의 오래된 결과, 재배포 조건이 명확하지 않은 부속 파일을 포함하지 않습니다.

검토 결과와 공개용 수정 판단은 [`docs/analysis_notes.md`](../docs/analysis_notes.md)에 기록했으며, 원본 프로젝트 폴더는 수정하지 않았습니다.
